## AD CREATIVE SPECIFICATIONS

### Reel / Video Ad
| Spec | Requirement |
|------|-------------|
| Aspect Ratio | 9:16 (vertical, full-screen) |
| Resolution | 1080 × 1920 px minimum |
| Duration | 15–30 seconds (sweet spot: 22–28 sec) |
| File Format | MP4 or MOV |
| Max File Size | 4 GB |
| Captions | Always ON — 85% of Reels are watched without sound |
| Safe Zone | Keep text/logo within center 75% — edges get cropped |
| Hook (First 3 sec) | Must be text on screen + voiceover — no slow intros |
| End Card | Logo + WhatsApp number + CTA button |

### Static Image / Story Ad
| Spec | Requirement |
|------|-------------|
| Feed (Square) | 1080 × 1080 px |
| Feed (Portrait) | 1080 × 1350 px (4:5 — gets more screen space) |
| Story / Reels cover | 1080 × 1920 px |
| File Format | JPG or PNG |
| Max File Size | 30 MB |
| Text on image | Keep below 20% of image area (Meta penalizes text-heavy images) |
| Font size | Minimum 30pt for mobile readability |

### Carousel Ad
| Spec | Requirement |
|------|-------------|
| Image per card | 1080 × 1080 px (square only) |
| Number of cards | 3–5 (5 is ideal for CCC curriculum reveal) |
| Headline per card | Max 40 characters |
| Description | Max 20 characters |
| CTA Button | "Learn More" or "Send Message" |

## AD COPY FRAMEWORK (For Every Ad)

Follow this structure — every ad you write must hit all 5 elements:

```
1. HOOK      — Stop the scroll in 3 seconds (pain or curiosity)
2. PROBLEM   — Amplify the pain they already feel
3. SOLUTION  — Introduce CCC as the answer
4. PROOF     — One stat, one credibility point, or one outcome
5. CTA       — One clear action (WhatsApp / Enquire Now)
```

## BIDDING STRATEGY

| Scenario | Bid Strategy | Why |
|----------|-------------|-----|
| Starting out (first 3 days) | **Lowest Cost** (auto) | Let Meta learn your audience |
| After 50+ leads collected | **Cost Cap** at ₹300–₹400/lead | Control cost per lead |
| Retargeting campaigns | **Lowest Cost** (auto) | Audience is small, no need to cap |
| Final 3 days (urgency) | **Highest Volume** | Burn remaining budget, maximize reach |

**Rule of thumb:** Never change ad sets in the first 7 days. Meta needs 50 conversion events to exit the "learning phase." Let it run.

## META ADS POLICIES — WHAT TO AVOID

These will get your ad rejected or account flagged:

| ❌ Don't Do This | ✅ Do This Instead |
|-----------------|-------------------|
| "Earn ₹1 lakh per month as a counsellor" | "Build a practice that serves students and families" |
| Before/After claims without proof | Show curriculum + tools, let outcomes speak |
| Stock photos of foreign people | Use Indian faces, Indian settings, Indian names |
| Text covering >20% of image | Keep image mostly visual, put text in caption |
| Claim "government recognized" without proof | "Srichakra Academy Certified" — your own brand |
| Exaggerated urgency ("Only 2 seats left!") if not true | Real seat count — honesty builds trust and avoids bans |
| Personal attribute targeting ("as a teacher, you...") | Describe the offer, not the person's identity |
